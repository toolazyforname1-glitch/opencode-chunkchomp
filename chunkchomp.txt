# ------------------------------------------------------------
# TAG TYPES
# ------------------------------------------------------------
# Two tags exist:
#   !COMPACT  MANDATORY - context is at or past the limit below,
#             every flagged chunk must be compacted.
#   ?COMPACT  OPTIONAL  - context is still small, the model decides
#             whether the chunk is worth compacting.
# A chunk flagged ?COMPACT turns !COMPACT by itself once the
# conversation crosses the limit.

# Context size (in tokens, whole conversation) at which ?COMPACT
# becomes !COMPACT.
